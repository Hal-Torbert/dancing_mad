# 絶・妖星乱舞 P4 タンク用視覚カンペ

サーバー通信・外部パッケージなしで動作する、イディル式準拠の個人用Webアプリです。

## 起動

`index.html` をブラウザで開くか、このフォルダで次を実行します。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

その後 `http://127.0.0.1:8765/` を開きます。

## 入力の簡略化

各GCで選ぶ個人パターンは次の4つです。

- 水圧縮（早／遅も選択）
- フォークライトニング（早／遅も選択）
- 加速度のみ（処理タイミングは自動）
- 加速度＋呪詛（処理タイミングは自動）

GC2はGC1の選択から、成立する2候補だけを有効にします。

## ファイル

- `index.html`: 1画面UI
- `styles.css`: レスポンシブ表示とアイコンスプライト
- `app.js`: 状態管理、付与規則、行動計算、SVG描画
- `assets/icon-source.png`: ユーザー提供のアイコン素材原本

## 対象範囲

初期版はGC1・炎・GC2・水までを対象とします。GC3、アラガンフィールド、死の超越、サンダガ／ブリザガは対象外です。
